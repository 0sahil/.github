# .github

*Default community health files for [@0sahil](https://github.com/0sahil)'s repositories.*

GitHub uses these files for any repository owned by this account that doesn't have its own copy. A file inside a repository always takes precedence over the default here.

| File | Purpose |
|---|---|
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | How to behave in the community |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to report issues and open pull requests |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability privately |
| [SUPPORT.md](SUPPORT.md) | Where to get help |
| [Issue templates](.github/ISSUE_TEMPLATE) | Bug report and feature request forms |
| [Pull request template](.github/pull_request_template.md) | Checklist shown when opening a pull request |

For more information, see GitHub's article on [creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
