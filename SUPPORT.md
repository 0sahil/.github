# Support

## How to get help

- **Read the docs first.** Each repository's README covers installation, usage and common questions.
- **Questions and ideas:** if the repository has Discussions enabled, start a discussion there. Otherwise open an issue.
- **Bugs:** open an issue using the bug report form. Search existing issues first, including closed ones.
- **Feature requests:** open an issue using the feature request form.
- **Security vulnerabilities:** don't open a public issue. Follow the [security policy](SECURITY.md).

## Response times

These projects are maintained in spare time. Responses may take a few days, and not every request can be accommodated. Clear reports with steps to reproduce get answered fastest.
